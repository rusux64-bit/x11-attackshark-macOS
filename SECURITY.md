# Security Policy

## Supported Versions

I actively maintain the latest stable release of Attack Shark X11 macOS and will prioritize security fixes for that version.

| Version | Security Updates |
|---------|------------------|
| Latest release | Supported |
| Older releases | Not supported |

I recommend using the latest available release to make sure you have the most recent fixes.

## Reporting a Security Issue

If you've found a security issue in Attack Shark X11 macOS, I encourage you to report it.

Please avoid opening a public GitHub issue for security-related problems, especially if the report contains details that could be used to exploit the vulnerability.

The best way to report an issue is through GitHub's **Private Vulnerability Reporting** feature, available under the repository's Security tab.

When submitting a report, please include as much of the following information as possible:

- A brief explanation of the vulnerability.
- The version of the application you're using.
- Steps to reproduce the issue.
- Any relevant logs, screenshots, or other technical details.
- An explanation of what you believe the potential impact could be.

You don't need to have all the answers. A clear description of what you discovered is a good starting point.

## What Happens Next?

I'll review the report, try to reproduce the issue, and assess its potential impact.

If the vulnerability is confirmed, I'll work on an appropriate fix and include it in a future release where possible.

I'll also do my best to keep the person who reported the issue informed throughout the process. The time needed to investigate and resolve a report will depend on its severity and complexity.

## Responsible Disclosure

I appreciate anyone who takes the time to report security issues responsibly.

Please give me a reasonable amount of time to investigate and address a vulnerability before sharing technical details publicly. This helps protect users while a fix is being prepared.

Security reports submitted in good faith are appreciated, and I have no intention of discouraging responsible security research.

## Scope

This policy covers security issues directly related to Attack Shark X11 macOS, including its application code and the way it interacts with the mouse and macOS.

Issues involving the physical mouse hardware, macOS itself, or unrelated third-party software fall outside the direct scope of this project.

If you're unsure whether something falls within the scope, feel free to report it anyway. I'll take a look.
